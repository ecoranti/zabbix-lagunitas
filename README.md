# Red Las Lagunitas — Monitoreo con Zabbix (laboratorio PPS)

Snapshot del laboratorio de monitoreo desarrollado para la Práctica Profesional
Supervisada (UNRC): Zabbix 7.0 en Docker, red WISP simulada con contenedores
Alpine (ICMP) y un AP UniFi U7 Pro Wall real monitoreado vía API REST.

> La API key de UniFi **no** está versionada: exportarla antes de correr los
> scripts del AP (`export UNIFI_API_KEY=...`).
